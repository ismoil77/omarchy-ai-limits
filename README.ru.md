# Лимиты ИИ в панели Omarchy

Лимиты ИИ-инструментов на вашем компьютере — **Claude, Codex и Gemini** — в панели
[Omarchy](https://omarchy.org), с переключателем между ними. Для каждого окна — понятный вывод
простыми словами вместо стены цифр, плюс полоса темпа и прогноз. Сделано так, чтобы читалось
людям со слабым зрением.

[English version](README.md)

![Попап, русский](docs/preview-ru.png)

В панели: `✻ [полоса] 9% 4ч22м н9%` — значок и полоса выбранного ИИ в цвете темпа, процент,
время до сброса и метка, когда внимания просит более длинное окно. Левый клик открывает окно,
**средний переключает на следующий ИИ**, правый обновляет. Показываются только те инструменты,
в которые на этом компьютере выполнен вход.

## Чем отличается

- **Говорит, что делать.** Каждое окно начинается с одной фразы: *«При такой скорости лимит
  кончится в пт 17:12, через 4 д 2 ч — раньше сброса.»* Остальные цифры — по клавише `D`.
- **Бережёт длинное окно, а не только короткое.** У окна 5 часов есть потолок, посчитанный по
  остатку недели: если выжимать каждое окно до 100%, в четверг не останется ничего.
- **Настоящие цифры со всех устройств.** Их отдаёт сервер провайдера, те же, что показывает
  его собственный CLI, поэтому работа на других компьютерах учитывается.
- **Доступность.**
  - текст не мельче 13 px и масштабируется (`textSize`: Normal, Large, Extra large);
  - цвет любого текста доводится до контраста WCAG AA (4,5:1) на фоне окна вашей темы —
    проверено на цветах всех 22 стандартных тем Omarchy;
  - статус — это слово и значок (✓ ▲ ✕), а не только цвет;
  - при крупном тексте окно прокручивается, а не обрезается;
  - `animations: false` отключает «плавание» полос.
- **Русский и английский** (`language`: `auto` — по языку системы).

## Какие ИИ поддерживаются

| ИИ | Откуда цифры | Что видно | Вход |
|---|---|---|---|
| **Claude** | OAuth-эндпоинт использования Anthropic (то, что показывает `/usage`) | окно 5 часов, неделя, недели моделей (например, Fable) | Claude Code |
| **Codex** | RPC `account/rateLimits/read` у `codex app-server`, запускается только на чтение | окна 5 часов / неделя или единственное длинное окно бесплатного плана и Go | Codex CLI |
| **Gemini** | `retrieveUserQuota` из Google Code Assist | суточная квота по семействам моделей: Pro, Flash, Flash Lite | Gemini CLI (вход Google) |

В каждый инструмент нужно войти его собственным CLI. Окна любой длины поддерживаются: окно до
6 часов считается по обычному времени, более длинное (сутки, неделя, 30 дней) — по вашим рабочим часам.

**Статус:** Claude и Codex используются каждый день и проверены на живых аккаунтах. Gemini написан по
документации API и покрыт тестами на формат ответа, но на живом аккаунте пока не подтверждён —
если цифры выглядят странно, откройте issue.

## Что нужно

- Omarchy с системой плагинов шелла (есть команда `omarchy plugin`).
- `python3` 3.8+ (только стандартная библиотека).
- Хотя бы что-то одно: Claude Code (подписка Pro/Max), Codex CLI, Gemini CLI (вход Google).
  У входа по API-ключу лимитов подписки нет.

## Установка

```bash
omarchy plugin add https://github.com/ismoil77/omarchy-ai-limits.git --enable
```

Плагины выполняются в шелле без песочницы — сначала прочитайте код, он небольшой.
Обновление: `omarchy plugin update ismoil.ai-limits`.

## Управление

- **Панель:** левый клик — окно; средний — следующий ИИ; правый — обновить.
- **Окно:** чипы сверху переключают ИИ (клик, `h`/`l` или `1`–`3`); `d` — подробности;
  `r` — обновить; `Esc` — закрыть. IPC: `omarchy-shell ismoil.ai-limits next|previous|select <id>|refresh|toggle`.

## Удаление

```bash
omarchy plugin remove ismoil.ai-limits
rm -rf ~/.cache/ismoil-ai-limits      # кэш цифр, по желанию
```

## Настройки

В записи виджета в `~/.config/omarchy/shell.json` или в настройках панели:

| ключ | по умолчанию | |
|---|---|---|
| `providers` | `all` | `all` или список, например `claude,codex` |
| `language` | `auto` | `auto`, `en`, `ru` |
| `textSize` | `Normal` | `Normal`, `Large`, `Extra large` — размер текста в окне и панели |
| `workFrom`, `workTo` | `8`, `23` | Часы местного времени, когда вы пользуетесь ИИ. Окна от суток считаются только по ним, чтобы ночи не делали вас «медленным». `0`–`24` — круглосуточно |
| `clock` | `24-hour` | или `12-hour` |
| `animations` | `true` | `false` отключает анимацию полос |
| `renewLogin` | `false` | `true`: самому обновлять истёкший вход в **Claude** (см. «Приватность») |
| `interval` | `60` | период обновления, секунды (не меньше 45); Codex и Gemini опрашиваются не чаще раза в 2 минуты |

## Приватность и что трогает плагин

Важно: виджет работает с вашими входами в ИИ.

- **Claude:** читает `~/.claude/.credentials.json` (или `$CLAUDE_CONFIG_DIR`) и отправляет токен
  доступа **только** на `https://api.anthropic.com/api/oauth/usage`.
- **Codex:** токены Codex виджет не читает. Он запускает `codex app-server` (только чтение, как это
  делает встроенная панель агентов Omarchy) и спрашивает у него лимиты; вход Codex ведёт сам.
- **Gemini:** читает токен доступа из `~/.gemini/oauth_creds.json` и отправляет его **только** на
  `https://cloudcode-pa.googleapis.com/v1internal` (`loadCodeAssist`, `retrieveUserQuota`). Токен
  Google он не обновляет: когда тот истёк, виджет так и пишет и ждёт, пока вы запустите `gemini`.
- **По умолчанию файл входа Claude никогда не записывается.** Когда токен Claude истекает, виджет
  пишет «вход истёк — запустите claude» и ждёт, пока Claude Code обновит его сам.
- **Включается явно: `renewLogin: true`.** Тогда при истёкшем (или отклонённом) токене Claude виджет
  обновляет его так же, как Claude Code: refresh-токен уходит **только** на
  `https://platform.claude.com/v1/oauth/token`, а новая пара записывается обратно в
  `.credentials.json` (атомарно, с теми же правами, остальные ключи сохраняются). Неудачное
  обновление не повторяется 10 минут. Refresh-токен меняется при каждом обновлении, поэтому уже
  запущенной сессии Claude Code, которая запомнила старую пару, может потребоваться перезапуск.
- Больше ничего не покидает компьютер. Кэш цифр — в `~/.cache/ismoil-ai-limits/`.

## Как выбирается цвет

- **зелёный** — темп ровный или медленнее, до сброса лимит не кончится.
- **жёлтый** — быстрее ровного темпа, близко к лимиту или больше доли этого окна от длинного.
- **красный** — при текущей скорости лимит кончится раньше сброса (или уже исчерпан).
  Один лишь высокий процент красным не бывает: 92% при нулевых тратах — это нормально.

## Разработка

```bash
tests/run.sh      # Python, Node, QML-движок Qt и `omarchy plugin validate`
```

`limit.py` — слой данных (по загрузчику на каждый ИИ, у каждого свой файл состояния), `Model.js` —
расчёты темпа и все фразы, `Strings.js` — тексты en/ru, `kit/` — общая подгонка цветов и помощники перевода (копия
[omarchy-widget-kit](https://github.com/ismoil77/omarchy-widget-kit)). Последние
три — чистые функции, их используют и виджет, и тесты. Набор тестов на Qt 6 `qmltestrunner`
пропускается, если его нет. После правок QML запускайте `omarchy restart shell` — горячая
перезагрузка иногда оставляет старый виджет.

**Новый ИИ:** напишите в `limit.py` функцию `fetch_<id>(state, now, renew)`, которая возвращает
`{"windows": [...], "plan": "..."}` (см. `make_window`) или бросает `Failure(kind)`, добавьте её в
`PROVIDERS`, `FETCHERS`, `DETECTORS`, задайте значок в `markOf` в `Widget.qml` и допишите тесты.
**Новый язык:** добавьте таблицу в `Strings.js` (тесты не пройдут, пока нет всех ключей и тех же
подстановок) и код языка в `LANGS`.
